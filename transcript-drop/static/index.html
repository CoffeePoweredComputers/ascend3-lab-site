What to bring, depending on the tool you used

VT Arc

Download the chat as JSON from Arc itself and upload it here. It downloads on the spot — no export request, no waiting — so this is the most dependable route of any tool on this page.

AI tools inside your editor or terminal

Claude Code, Codex, Copilot and Cursor have no export button; they write logs to hidden folders. Run this in your project folder and upload the file it creates: 

curl -sSO <server>/collect_ai_logs.py
python3 collect_ai_logs.py --repo .

It only picks up sessions from that one project folder, and it uploads nothing — the bundle is written to interaction-logging/ inside your project and excluded from git, so your conversations are never pushed where your teammates can read them. Upload that file here. Re-running is safe: submitting again updates a session rather than filing it twice.

ChatGPT

Open the conversation, choose Share, and paste the link into the share-link box below. We read the conversation from it, including when each message was sent and which model answered.

A share link makes that one conversation readable by anyone who has the URL. If you would rather not share it, paste the conversation text instead.

Claude

Share links cannot be read automatically, so either paste the conversation text, or go to Settings → Privacy → Export data (web app and Claude Desktop only, not iOS or Android). If you export, open conversations.json first — if it is empty, the export did not capture your chats and there is nothing to submit. The projects/ folder holds documents you uploaded, not conversations.

Anything else

Copy the conversation text and paste it. Select the messages themselves — not "view page source".
