What the codes say together.

## The topic map

Each code with how many cards it is on. Open a code to read every card it is on.

- Look at the largest codes first, then at what is small that you expected to be large.
- A code on very few cards may belong inside another. Note it for the next codebook version.

## Themes

A theme is a claim about the data that several codes support. It is not a category name.

- Weak: "AI". Better: "Students ask who answers for what an AI system does, more than whether it works."
- Give each theme a name and a statement of one or two sentences.
- Put each code in one theme, or in none.
- Check the statement against the cards: open each code in it and read.

Do this at a meeting. Anyone can edit. If a model is set up, the lead can ask it for a first proposal, once; treat it as a draft to argue with.

## Then

Export. `final_codes.csv` has what every card was coded as, and `themes.csv` has the themes.
