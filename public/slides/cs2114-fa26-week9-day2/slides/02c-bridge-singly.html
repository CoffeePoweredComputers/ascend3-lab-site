With prev and next on every node, which references change when curr is removed?

Last class put a list on a singly linked chain. Step 1. This is that chain, with firstNode and lastNode. To remove D, the last node, the method has to set C’s next to null and set lastNode to C. lastNode refers to D, not to C, so the method walks from firstNode: A, then B, then C. With n nodes that is n − 1 visits. Step 2. Today every node also has a prev reference, so each link is two references: next arrows are drawn above the chain and prev arrows below it. D’s prev refers to C. The node before D is one step away, with no walk. Step 3. Ask the room which references change when curr is removed from the middle, from the front and from the back. Part 1 walks it.
