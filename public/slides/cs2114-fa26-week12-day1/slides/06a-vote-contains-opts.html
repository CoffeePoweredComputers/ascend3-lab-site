How could you improve contains(anEntry) for a SortedList so that it still works correctly but may run faster in the average case?

  1. A

    Have contains(anEntry) call an existing helper like indexOf(anEntry) and return whether it’s ≥ 0.

  2. B

    Exit the loop when list[index].compareTo(anEntry) < 0, since earlier elements are smaller.

  3. C

    Exit the loop when list[index].compareTo(anEntry) > 0, because once you pass the possible position, the entry can’t appear later.

  4. D

    Traverse the list in reverse order, so larger entries can be found faster

  5. E

    Traverse the list from both ends (start by checking the first/last elements, and on each iteration move inwards to check the next two), so that both large and small elements can be found quickly.

Answer: C (instructor-confirmed) — once list[index] is larger than anEntry, every later entry is larger too, so the loop can stop and return false.
