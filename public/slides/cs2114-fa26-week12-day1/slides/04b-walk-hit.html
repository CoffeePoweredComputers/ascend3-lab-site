The same loop and the same array, now for 12, which is in the list. Step 1: found is false and index is 0. Steps 2 to 4: 12 is compared with 3, 5 and 8, and none is equal. Step 5: at index 3, equals is true, so found is set to true. That cell takes the blue edge. Four compares so far. Step 6: index++ still runs, so index is 4. Then the while test checks !found first, and !found is false, so the loop ends without another compare. Step 7: return found returns true after four compares. The loop already stops early for an entry that is present. For an absent entry, as on the last slide, it ran all eight compares, although every entry after 12 was larger than 9.
