The height is 1 more than the taller subtree, and null has height 0

A walkthrough of a recursive height method on the same five-value tree, under a program-counter bar. The method returns 0 if the node is null, and otherwise returns 1 plus the larger of the heights of its left and right children. On the right, the tree with a blue ring on the node of the running call; each returned height appears beside its node in a blue pill. Step one: height of 10 checks for null and needs the heights of both subtrees. Step two: the calls go down the left side to 7; both of its children are null and return 0, so 7 returns 1. Step three: the left child of 3 is null, so 3 returns 1 plus the larger of 0 and 1, which is 2. Step four: on the right side, 20 returns 1 and 12 returns 2. Step five: an orange path draws from 10 through 3 to 7, and 10 returns 1 plus the larger of 2 and 2, which is 3, the number of levels on the longest path. Step six, in maroon: a leaf has height 1 and null has height 0, which is how CE 13’s height method counts.

height, counting levels (the deck’s version)

  1. int height(BinaryNode<T> node) {
  2. if (node == null) return 0;
  3. return 1 + Math.max(height(node.getLeftChild()),
  4. height(node.getRightChild()));
  5. }

height(10) checks for null, then needs the heights of both of its subtrees.

The calls go down the left side to 7. Both of its children are null and return 0, so 7 returns 1 + max(0, 0) = 1.

The left child of 3 is null, height 0, so 3 returns 1 + max(0, 1) = 2.

On the right side, 20 returns 1, and 12 returns 1 + max(0, 1) = 2.

10 returns 1 + max(2, 2) = 3, the number of levels on the longest path.

A leaf has height 1 and null has height 0, which is how CE 13’s height() counts.

The course’s slides do not have this exact method; this is the deck’s version, written in the same style, and it counts the way the votes and CE 13 do. Step 1: height(10) first checks for null. 10 is not null, so it needs the heights of its two subtrees. Step 2: the calls go down the left side, 10 to 3 to 7. 7’s children are both null and return 0, so 7 returns 1 + max(0, 0) = 1. A leaf has height 1. Step 3: 3’s left child is null, height 0, and its right child, 7, has height 1, so 3 returns 2. Step 4: the right side is the same shape: 20 returns 1 and 12 returns 2. Step 5: 10 returns 1 + max(2, 2) = 3. The orange path is one of the two longest paths, three levels. Step 6: this is CE 13’s height(): a leaf is 1 and an empty tree is 0.
