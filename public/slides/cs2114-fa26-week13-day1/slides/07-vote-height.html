A peer-instruction question. Under the title, the question stem in muted type: given that the height of a tree is 1 more than the number of edges from the root to the deepest node, if a binary tree has n nodes that either have 0 or 2 children and all leaves on the same level, what is the height of the tree? Under it the six options as rows, each led by a maroon disc with its letter: A, log2 of n; B, log2 of n minus 1; C, 2n plus 1; D, log2 of n plus 1; E, 2n minus 1; F, 2n. Two clocks sit in the top right corner: a ninety-second vote timer and a two-and-a-half-minute discussion timer. The first press starts the vote timer; the second starts the discussion timer and ends the vote timer. Nothing else builds.

Given that the height of a tree is 1 more than the number of edges from the root to the deepest node, if a binary tree has n nodes that either have 0 or 2 children and all leaves on the same level, what is the height of the tree?

  1. A

    log2(n)

  2. B

    log2(n-1)

  3. C

    2n+1

  4. D

    log2(n+1)

  5. E

    2n-1

  6. F

    2n

Answer: D — log2(n+1) [key from the PrairieLearn twin dataStructures/trees/tree_formula; confirm in Runestone’s results view]. The twin shows the last three options as powers, 2^(n+1), 2^(n−1) and 2^n, where Runestone shows 2n+1, 2n-1 and 2n; the slide follows Runestone. The first press starts the 1:30 vote clock; students answer on their own first. The second press starts the 2:30 discussion clock, and the third moves on. If a group does not know where to start, ask them to count the nodes of the height-3 tree from slide 06, then draw one more level and count again, and try each option on those two trees.
