A peer-instruction question. Under the title, the question stem in muted type: given that the height of a tree is 1 more than the number of edges from the root to the deepest node, if a binary tree of height 7 has nodes that either have 0 or 2 children and all leaves on the same level, how many nodes are in the tree? Under it the six options as rows, each led by a maroon disc with its letter: A, 127; B, 128; C, 31; D, 32; E, 63; F, 64. Two clocks sit in the top right corner: a ninety-second vote timer and a two-and-a-half-minute discussion timer. The first press starts the vote timer; the second starts the discussion timer and ends the vote timer. Nothing else builds.

Given that the height of a tree is 1 more than the number of edges from the root to the deepest node, if a binary tree of height 7 has nodes that either have 0 or 2 children and all leaves on the same level, how many nodes are in the tree?

  1. A

    127

  2. B

    128

  3. C

    31

  4. D

    32

  5. E

    63

  6. F

    64

Answer: A — 127 [key from the PrairieLearn twin tree_formula_nodes; confirm in Runestone’s results view]. The first press starts the 1:30 vote clock; students answer on their own first. The second press starts the 2:30 discussion clock, and the third moves on. If a group is stuck, ask how many nodes the seventh level holds, and then how many all seven levels hold together; or ask them to use the answer to Vote 1 with h = 7.
