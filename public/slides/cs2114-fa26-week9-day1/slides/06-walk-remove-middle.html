LinkedList: remove, the case p > 0

  1. T remove(int p) {
  2. Node nodeBefore = getNodeAt(p - 1);
  3. Node nodeToRemove = nodeBefore.next;
  4. nodeBefore.next = nodeToRemove.next;
  5. numberOfEntries--;
  6. return nodeToRemove.data;
  7. }

remove(2) on A, B, C, D. getNodeAt(1) starts at firstNode, at A.

It moves one node along, so nodeBefore refers to B.

nodeToRemove = nodeBefore.next, so nodeToRemove refers to C.

nodeBefore.next = nodeToRemove.next sets B’s next to D. The chain no longer includes C.

The method returns C. After the return, nothing refers to C’s node. The list is A, B, D.
