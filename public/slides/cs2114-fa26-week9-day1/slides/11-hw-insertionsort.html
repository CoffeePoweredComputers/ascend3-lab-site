This week’s homework on PrairieLearn has four problems at 10 points each, and your best two count. It is due Friday October 23 at 11:59 PM. The four problems are the steps of one algorithm, insertion sort on a linked list, and the last one puts them together. The class is a little different from the module’s: it keeps firstNode and size, and its Node has next(), not getNext(). Step 1. Split In Two. Make two new lists: one with the first value of the given list, one with everything else. The given list must not change. Check a one-item list and an empty list. Step 2. Find Node Before. Given a value in a sorted list, return the node before the node holding it. In the example, findNodeBefore(9) returns the node holding 8. The first value has no node before it, so the answer is null, and a value that is not in the list throws IndexOutOfBoundsException. This is the first half of remove from today: the node before is the one whose next changes. Step 3. Insert After Node. Link a new node in after a given node. This is slide 04b: set the new node’s next before you change the given node’s next. Step 4. Insertion Sort. Take each node from the unsorted part and insert it where it belongs in the sorted part, by changing links. Swapping the data in the nodes does not count.
