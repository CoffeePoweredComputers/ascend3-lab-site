Which of these is a way to write remove()?

A peer-instruction question about the ArrayBag class. On the left, the given private method removeEntry, which takes an index: it starts result at null; if the bag is not empty and the index is at least zero, it copies the entry at that index into result, copies the last entry into that index, nulls the last slot and decrements numberOfEntries; then it returns result. On the right, four candidate bodies for the public remove method, labeled A through D. A calls removeEntry with numberOfEntries minus 1 and returns the result. B sets result to null, and if numberOfEntries is greater than zero nulls the last slot and decrements the count, then returns result. C calls removeEntry with getIndexOf of null and returns the result. D returns removeEntry of numberOfEntries with a post-decrement.

Answer: A. The question as printed: “Which of the following 4 implementations would be a way to write a remove() method for an ArrayBag, given the following removeEntry(int) method?” A hands removeEntry the index of the last entry, numberOfEntries minus 1, and removeEntry does the rest — returns it, nulls the slot, counts down. B never reads the entry out of the array: result stays null, so the slot is cleared and whatever was in it is gone — a remove that loses what it removed. C asks getIndexOf for the index of null; getIndexOf calls anEntry.equals on it, and null.equals throws a NullPointerException as soon as there is an entry to compare. D passes numberOfEntries-- : the old count, which is one past the last entry, and the count has already come down before removeEntry runs — so removeEntry reads a null slot, returns null, and counts down a second time.
