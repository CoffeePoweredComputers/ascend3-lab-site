inorder: visit between the two calls

  1. void inorder(BinaryNode<T> node) {
  2. if (node != null) {
  3. inorder(node.getLeftChild());
  4. visit(node.getData());
  5. inorder(node.getRightChild());
  6. }
  7. }

A’s call goes left to B, and B’s call goes left to D. D has no left child, so D is printed first.

D has no right child, so D’s call returns. B’s left call is finished, so B is printed.

B’s call goes right to E, and E’s call goes left to F. F has no left child, so F is printed.

F’s call returns, and E is printed between its two calls.

E’s call goes right to G. G has no children, so G is printed.

G, E and B return. A’s left subtree is finished, so A is printed.

A’s call goes right to C. C has no left child, so C is printed.

C’s call goes right to H. H has no children, so H is printed.

The left subtree first, then the root, then the right subtree: D B F E G A C H.
