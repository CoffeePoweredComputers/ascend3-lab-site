int unsorted = data[i] copies 25 out of slot 1. Slot 1 can now take a larger entry.

int j = i - 1 sets j to 0, the last slot of the sorted part.

j >= 0 is true, and data[0] > unsorted compares 64 with 25. 64 is larger, so the loop body runs.

data[j + 1] = data[j] copies 64 into slot 1, one slot to the right.

j-- sets j to −1, so j >= 0 is false and the loop ends.

data[0] = unsorted puts 25 in slot 0. One compare and one shift, and the array reads 25 64 12 22 11.

This is the reading’s insertion sort with the public and private static modifiers left out. insertionSort calls insertInOrder once for each i from 1 to the last index. Each call takes the entry at i and inserts it into the part to its left, which is already sorted. The two counters count compares of data[j] with unsorted, and shifts, the copies data[j + 1] = data[j]. Step 1: unsorted = data[i] copies 25 out of slot 1. The array still holds a 25 there, but it will be overwritten, so the slide draws it as moved. Step 2: j starts at the slot just left of i. Step 3: the loop test. j >= 0 is true, and 64 is greater than 25: one compare. Step 4: 64 is copied one slot right: one shift. Step 5: j becomes −1, so the first half of the test fails and the second half is not evaluated; that is why the count stays at 1. Step 6: 25 goes into slot j + 1, which is slot 0. The first two slots are now in order, and 12, 22 and 11 have not been touched. Ask: what does the next call, with i = 2, do with 12? The next slide runs the other three calls.
