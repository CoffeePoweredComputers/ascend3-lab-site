findSmallest(a, 0, 5) starts with smallestIndex = 0, the slot that lh names.

With i = 1, a[1] < a[0] compares 25 with 64. 25 is smaller, so smallestIndex becomes 1.

With i = 2, 12 < 25 is true, so smallestIndex becomes 2.

With i = 3, 22 < 12 is false, so smallestIndex stays 2.

With i = 4, 11 < 12 is true, so smallestIndex becomes 4.

The loop ends at i = 5. findSmallest returns 4, so rh is 4.

swapElements(a, 0, 4) copies 64 into temp, 11 into slot 0, and temp into slot 4.

Four compares and one swap. lh++ makes lh 1. 11 is in its final slot, and the array reads 11 25 12 22 64.

The selection sort from the course’s SelectionSort slides. lh, the left hand, is the slot being filled; rh, the right hand, is the index of the smallest entry from lh to the end, which findSmallest returns. The array is named a here so that the lines fit. swapElements is three lines: temp = a[p1]; a[p1] = a[p2]; a[p2] = temp. Step 1: findSmallest starts by assuming the smallest is at p1, slot 0. Steps 2 to 5: i runs from 1 to 4. Each press is one compare, a[i] with the smallest found so far. 25 is smaller than 64, 12 is smaller than 25, 22 is not smaller than 12, and 11 is smaller than 12. Four compares. Step 6: the loop ends and findSmallest returns 4; that is rh. Step 7: one swap. 64 goes to temp, 11 to slot 0, temp to slot 4. Step 8: lh moves to 1.
