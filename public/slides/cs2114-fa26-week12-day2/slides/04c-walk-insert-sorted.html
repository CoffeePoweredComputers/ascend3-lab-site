Same code, new input: the sorted array from the last slide. Steps 1 to 4: each call holds the entry at i, compares it once with the entry to its left, finds that entry is not larger, and writes the held value back into the slot it came from. One compare per call, no shift. Step 5: for n entries in order, insertion sort makes n − 1 compares and no shifts, which is linear. On the vote’s input it made ten compares and nine shifts.
