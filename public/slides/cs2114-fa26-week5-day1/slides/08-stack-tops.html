Three ways to build a stack

A line across the top names the stack interface — push, pop, peek, isEmpty, clear; last in, first out — and says every drawing shows the stack after push A, push B, push C. Three columns arrive one per step. One, a linked chain: a blue pill labelled topNode points at a node holding C, which points at B, which points at A, whose next is null; the caption says the top is the first node. Two, an array with the top at the last occupied index: six cells holding A, B, C and three free cells, with an orange marker topIndex equals 2 over the cell holding C; the caption says the top is stack at topIndex. Three, an array with the top at index 0: six cells holding C, B, A and three free cells, with an orange marker top over cell 0; the caption says the top is stack at 0 and the bottom is the last occupied cell.
