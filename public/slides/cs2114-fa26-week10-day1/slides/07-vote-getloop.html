If a singly linked list only lets you access elements via an index-based get(i) call, what’s the time complexity of traversing the list using a loop that visits every element by calling get(0), get(1), …, get(n)?

    O(1)

  2. B

    O(log n)

  3. C

    O(n)

  4. D

    O(n²)
