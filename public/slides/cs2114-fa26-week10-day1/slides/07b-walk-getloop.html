The code is the client loop from the stem and a get method with the getNodeAt loop from the 9.1 video: currentNode, counter and givenPosition, positions from 0. In the course code the public method is getEntry and the loop is in the private getNodeAt; here they are one method so it fits. The for header is split over two lines for the same reason. Step 1. get(0) sets currentNode to firstNode, and counter < 0 is false, so the loop body does not run. One node visited. Step 2. get(1) starts at firstNode again. It does not remember where get(0) stopped. Two visits, three in all. Step 3. get(2), three visits, six in all. Step 4. get(3), four visits, ten in all. Step 5. The client loop made four calls, and each one walked from firstNode. 1 + 2 + 3 + 4 = 10. Step 6. For n nodes the sum is 1 + 2 + … + n = n(n + 1)/2, which is about n²/2, and that grows like n².
