Consider the following program:

the program

  1. for (int i = 0; i < arr.length; i++) {
  2. for (int j = i; j < arr.length; j++) {
  3. System.out.println(arr[i] + arr[j]);
  4. }
  5. }

What is its time complexity, in terms of the length of the array?

  1. A

    O(log n)

  2. B

    O(n)

  3. C

    O(n log n)

  4. D

    O(n²)

Answer: D — O(n²) [no PrairieLearn twin; by counting, n + (n − 1) + … + 1 = n(n + 1)/2 prints; confirm in Runestone’s results view before class].
