RECURSION · THE CALLS GO DOWN

fact(3) calls fact(2), which calls fact(1)

A walkthrough of a six-line method, int fact of int n: if n equals 1, return 1; otherwise return n times fact of n minus 1. A program-counter bar moves through the lines. On the right, the call stack drawn as a column of frames inside a thin box, top up, with main at the bottom waiting on fact of 3. Press one: fact of 3 is called and a new orange frame grows in on top, with n equals 3. Press two: n is not 1. Press three: the last line needs fact of 2 first, so the frame turns grey and a note beside it says waiting on line 5. Presses four to six do the same for fact of 2, with its own n equals 2, on top. Presses seven and eight: fact of 1 grows in on top with n equals 1, and n equals 1 is true: the base case. Press nine: return 1; three frames are waiting under it. The captions say each call gets its own frame with its own n, and that this is the Week 5 stack: the newest call is on top.

fact: n! = n × (n − 1)!

  1. int fact(int n) {
  2. if (n == 1) {
  3. return 1;
  4. }
  5. return n * fact(n - 1);
  6. }

main calls fact(3). A new frame goes on top of the call stack, with its own n = 3.

Is n == 1? n is 3, so no.

To return 3 * fact(2), it needs fact(2) first. fact(3) waits on line 5.

fact(2) gets its own frame and its own n = 2. The n = 3 below is untouched.

Is n == 1? n is 2, so no.

2 * fact(1) needs fact(1) first. fact(2) waits on line 5 too.

fact(1): a third frame, n = 1. Newest call on top: this is the Week 5 stack.

Is n == 1? Yes. This is the base case.

fact(1) returns 1 without calling anything. Three frames are waiting under it.

The 7.3 module’s factorial with short names: fact of n is n times fact of n minus 1, and fact of 1 is 1. One new idea: the method calls itself. Watch the stack on the right; it is the same stack as Week 5, holding method calls instead of strings. Step 1 — main calls fact(3): a new frame on top, with its own n = 3. Step 2 — n is not 1. Step 3 — to compute 3 * fact(2) it has to call fact(2) first, so fact(3) stops on line 5 and waits. Step 4 — fact(2) gets its own frame. Two different n’s exist now, 3 and 2, one per frame; nothing overwrites the other. Step 5 — n is not 1. Step 6 — fact(2) waits on line 5 for fact(1). Step 7 — fact(1): a third frame, newest on top. Step 8 — n == 1: this is the base case, the case the method answers without calling itself. Step 9 — fact(1) returns 1. Ask: where does that 1 go? Next: the answers come back up.
