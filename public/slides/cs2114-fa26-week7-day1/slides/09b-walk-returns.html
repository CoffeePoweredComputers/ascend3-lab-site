Each answer goes down to the frame that waited for it

Press two: the fact of 1 frame fades away and the pill travels down into fact of 2, which turns orange again; its note now reads return 2 times 1. fact: n! = n × (n − 1)!

  1. int fact(int n) {
  2. if (n == 1) {
  3. return 1;
  4. }
  5. return n * fact(n - 1);
  6. }

Base case: fact(1) returns 1.

fact(1)’s frame pops. The 1 goes to fact(2), which was waiting on line 5: 2 * 1.

fact(2) returns 2.

fact(2)’s frame pops. fact(3) gets its 2 and can finish: 3 * 2.

fact(3) returns 6.

fact(3)’s frame pops and 6 reaches main. The stack is back where it started.

The calls went down: 3, 2, 1. The answers came back up: 1, 2, 6.

The same picture, picking up where the last slide stopped: three fact frames on top of main, fact(1) at the base case. Step 1 — fact(1) returns 1: the blue pill is the returned value. Step 2 — fact(1) is finished, so its frame comes off the stack, and the 1 goes back to whoever called it: fact(2), which was waiting in the middle of line 5. Now it can do 2 * 1. Step 3 — fact(2) returns 2. Step 4 — its frame pops, and fact(3) gets the 2 and finishes 3 * 2. Step 5 — fact(3) returns 6. Step 6 — its frame pops and main gets 6.
