Fix it — and work out how you would explain the problem to the coworker who wrote it.

Your coworker wrote a method that takes three Person objects and returns the oldest of them; it fails whenever one or more of the parameters is null. The code is on screen from the start — read the shape out loud before any step: three parameters, a chain of comparisons, every branch calls getAge on something.
