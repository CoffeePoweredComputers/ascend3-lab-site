Answer: line 2 throws first, on whichever of personA or personB is null — but every line here has the same bug, so patching line 2 alone just moves the crash. The useful move is to name the rule: you cannot call a method on a reference until you know it points at something. Then let them argue about where the checks go; handling the nulls up front, before any comparison, is much easier to read than a null test inside every branch.
