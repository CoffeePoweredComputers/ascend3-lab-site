Project 1 is a general introduction to Java — no data structures — and its brief names exactly two technical key words; this slide is those two words and nothing else. Step 1 — object-oriented Java: multiple classes with clear, separate responsibilities, arrays where they fit, and no one class doing everything. Point at the constellation: three small classes, each with one job, wired together — if one box holds all the code, the design part of the grade has nowhere to live. Step 2 — robust exception handling, told exactly as the overview tells it: the program expects a number and the user types abc. The maroon cross is the untrained fate: an unhandled exception and a dead program. Step 3 — the trained fate: validate the inputs that actually matter, fail gracefully, catch it and re-prompt. Say the warning out loud: this does not mean wrapping everything in empty try/catch blocks — an empty catch is not handling, it is hiding. Step 4 — that is the whole technical list. The overview’s third requirement is GitHub — collaborate with version control and turn in through it — and the standing advice is keep it small: an MVP that works beats an ambitious app that does not.
