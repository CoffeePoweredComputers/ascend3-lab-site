Write toString for the ArrayBag

A coding-practice prompt. Across the top, the task: return the items currently in the bag in the form open bracket, item, comma, item, comma, item, close bracket, in the order they appear in the underlying array; each item except the last is followed by a comma and a space; an empty bag returns a pair of empty brackets. Left, an excerpt of ArrayBag.java: the three fields — the contents array, MAX equal to 25, and numberOfEntries — the constructor that allocates a 25-slot Object array, and the toString stub with its TODO comment returning null. Return the items in the bag as [item, item, item], in the order they appear in the array. Each item except the last is followed by a comma and a space. An empty bag returns "[]".

Read the task once, point at the example, and give them eight minutes in their vote groups; the solution never goes on screen — PrairieLearn grades it. Hint 1 when the first hands go up: the array has 25 slots and the bag has five things in it, so which number is the loop bound? Ring the two lines. The two wrong bounds are both visible in the output, not as exceptions: i <= numberOfEntries prints an extra null, i < contents.length prints twenty of them. Hint 2 for the fencepost: every item but the last is followed by a comma and a space — either test for the last index, or add the separator before every item after the first. Hint 3: an empty bag must return the two brackets and nothing else, which a loop that runs zero times gives for free. For me: a StringBuilder starting with the open bracket, a for loop from 0 to numberOfEntries minus one appending the item and, when i is less than numberOfEntries minus one, a comma and a space, then the close bracket. Plant: the same bound as removeEntry — both votes and this workout turn on numberOfEntries, never on the array’s length.
