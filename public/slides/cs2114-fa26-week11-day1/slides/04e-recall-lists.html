Select the most accurate steps to remove a node that contains a designated element from a singly linked list with a head and tail reference

A recall of a Week 9 peer-instruction question. The heading is the question: select the most accurate steps to remove a node that contains a designated element from a singly linked list with a head and tail reference. Below it, four long options, each led by a maroon disc with its letter. A: if it's not the first node, then find the node that contains the designated element, get a reference to the node before it, reset the next reference of the node before it to be the next reference of the node containing the designated element; removing the first node would be a special case. B: if it's not the first or last node, then the same steps; removing the first or last node would each be a special case. C: if it's not the last node, then the same steps, with no special case named. D: if it's not the first node, then find the node that contains the designated element, reset the next reference of that node to be the node before it. On the one step, four short verdicts appear under the options, A, C and D struck through in turn and B, both ends special, left standing.

  1. A

    If it’s not the first node, then find the node that contains the designated element, get a reference to the node before it, reset the next reference of the node before it to be the next reference of the node containing the designated element. Removing the first node would be a special case.

  2. B

    If it’s not the first or last node, then find the node that contains the designated element, get a reference to the node before it, reset the next reference of the node before it to be the next reference of the node containing the designated element. Removing the first or last node would each be a special case.

  3. C

    If it’s not the last node, then find the node that contains the designated element, get a reference to the node before it, reset the next reference of the node before it to be the next reference of the node containing the designated element.

  4. D

    If it’s not the first node, then find the node that contains the designated element, reset the next reference of that node to be the node before it.

  1. tail not moved
  2. both ends special
  3. head not moved
  4. loops the chain
Answer: B — if it’s not the first or last node, … removing the first or last node would each be a special case [ASSUMED from the PL twin u11q05_sll_removenode_d, which is this question word for word; confirm in Runestone’s results view]. Show of hands, then the answer. A, B and C share the middle steps: find the node, get the node before it, and set that node’s next to the removed node’s next. The list has a head and a tail reference, and each end needs one more step. Removing the first node changes head, and there is no node before it. Removing the last node changes tail to the node before it. A names only the first node, so tail is left on the removed node. C names only the last node, so head is never changed and the first node has no node before it. D sets the found node’s next back to the node before it, so the node is not unlinked and the chain gains a loop. This topic had four questions on Test 2. Next: the testing question from Week 2.
