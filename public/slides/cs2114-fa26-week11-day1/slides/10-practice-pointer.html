The practice test is on PrairieLearn: Assessments, then Test #2 Practice. It stays open until December 31, so you can use it before the Redo this week. It has a 45-minute limit, the same as Test 2. Each attempt gives you a new set of 19 questions, so you can take it more than once. It is not for credit. The number on each row of the chart is the question’s number in the practice: if you lost points on the circular queue question, that row says 2, and question 2 of every practice attempt is a circular queue question. Find the rows that apply to you and work those practice questions. Next is the Redo.
