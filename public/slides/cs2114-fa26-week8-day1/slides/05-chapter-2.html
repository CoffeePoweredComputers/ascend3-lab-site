A deque: each node knows both neighbours

Part 2. A deque, a double-ended queue, adds and removes at both ends. Removing at the back means finding the node before the last one, and a singly linked chain cannot go backwards. So the deque in the videos uses a doubly linked node: each node has prev as well as next.
