Each node in a deque has prev and next

Part 2. A deque, a double-ended queue, adds and removes at both ends. Removing at the back needs the node before the last one, and a node in a singly linked chain has no reference to the node before it. So the deque in the videos uses a doubly linked node, which has prev as well as next.
