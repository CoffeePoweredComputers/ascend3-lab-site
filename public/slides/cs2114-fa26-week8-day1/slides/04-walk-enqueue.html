LinkedQueue: enqueue (newEntry shortened to x)

  1. void enqueue(T x) {
  2. Node newNode = new Node(x, null);
  3. if (isEmpty()) {
  4. firstNode = newNode;
  5. } else {
  6. lastNode.setNext(newNode);
  7. }
  8. lastNode = newNode;
  9. }

enqueue(A) on an empty queue. A new node: data A, next null.

isEmpty() is true: firstNode is null.

firstNode = newNode. The new node is the front.

lastNode = newNode. It is the back as well: both references point at the one node.

enqueue(B). A new node holding B.

The queue is not empty, so the else runs.

lastNode.setNext(newNode): the back node, A, now links to B.

lastNode = newNode: lastNode moves to B. firstNode did not move.

enqueue(C). A new node holding C; the queue is not empty.

lastNode.setNext(newNode): B links to C.

lastNode moves to C.

enqueue touches only lastNode, however long the chain is.

A new entry goes to the back. Step 1 — enqueue(A) on an empty queue: the constructor makes a node with data A and next null. The orange tint marks newNode, the node this call is building. Step 2 — isEmpty() is true, because firstNode is null. Step 3 — firstNode = newNode: the new node is the front. Step 4 — lastNode = newNode, after the if: the one node is the back too. Both references point at the same node; remember that state, it comes back in Vote 2. Step 5 — enqueue(B): a second node. Step 6 — not empty, so the else. Step 7 — lastNode.setNext(newNode): the old back node, A, now links to B. Step 8 — lastNode moves to B. Point out that firstNode has not moved since step 3. Steps 9 to 11 — enqueue(C), the same: C is linked after B and lastNode moves to C. Step 12 — enqueue never walks the chain. It reads lastNode, writes one link and moves lastNode, whether the queue has three nodes or three thousand. Next: dequeue, at the other end.
