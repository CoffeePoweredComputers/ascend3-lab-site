Taxonomies — SOLO

How we evaluate responses

Example: Student explaining a code segment

  • Prestructuralmisses the point“it’s a loop with an if.”
  • Unistructuralone relevant aspect“it compares numbers.”
  • Multistructuralparts, unlinked“loops, compares, updates max.”
  • Relationalparts integrated“returns the biggest number.”
  • Extended abstractgeneralized“a linear scan, like sum or min.”
stats.py
class Stats:    def __init__(self, nums):        self.nums = nums    def total(self):        return sum(self.nums)    # explain this method    def biggest(self):        m = self.nums[0]        for n in self.nums:            if n > m:                m = n        return m

Key takeaways

  • CLASSROOM TEST OR HOMEWORK

    Score the rung each response reaches, not just right/wrong.

  • Pre/post intervention test

    Success is responses climbing rungs from pre to post.
