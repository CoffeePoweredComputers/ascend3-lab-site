A rubric all you need? (other than unit-tests)

230 student Java code writing submissions — an OOP exam plus 25 algorithms problems — graded by LLMs with the instructor’s rubric in the prompt and compared against human graders.

Specificity wins: question-specific rubrics beat generic ones on the diverse, hard problems

Fair (according to human): the grader is neither harsher nor more generous than the humans

Consistent: when every student answers the same problem, a generic rubric grades just as well

Key takeaway

As you add a rubric and gradually increase its specificity to a given problem the results improve.
