[~50s · 3 clicks] Recap: so far the LLM has been the grader for two hard cases — natural-language responses, historically the hard thing to auto-grade in CS and beyond, and (just now) code writing, where a unit test's pass/fail isn't the grade and the rubric is. (1) Our other question formats were always easy to auto-grade: code runs against unit tests, a tracing problem has an input and an expected output, multiple choice has a key. (2) But think more broadly — put the question up: if leveraging these models effectively is itself a learning objective, how do we assess that? Give the room a beat to sit with it. (3) Uncover the answer key: grade the student on their ability to get the model to do stuff. The main mechanism is code generation, so build the autograding process around the code generated from the student's prompt — that's the next slide.
