  2. Link q = p.getNext();
  3. Link r = q.getNext();

  5. q.setNext(null);

p refers to the first node, the one holding 20.

q refers to p’s next: the node holding 30.

r refers to q’s next: the node holding 10.

p.setNext(r): the node holding 20 now points to the node holding 10.

q.setNext(null): the node holding 30 now points to null.

r.setNext(q): the node holding 10 now points to the node holding 30. Nothing references the node holding 5.

p.next is the node holding 10; p.next.next is the one holding 30; its data is 30.

Prints 30. The chain is now 20, 10, 30.

  1. 10
  2. 30
  3. 5
  4. null
  5. Nothing; A Null Pointer Exception is thrown
Answer: B — 30. Walk one line at a time; each setNext changes one reference. Step 1: p refers to the first node, 20. Step 2: q refers to 30’s node. Step 3: r refers to 10’s node. Step 4: p.setNext(r) — 20’s node now points to 10’s node. Step 5: q.setNext(null) — 30’s node now points to null. Step 6: r.setNext(q) — 10’s node now points to 30’s node. Nothing references the node holding 5; it will be garbage collected. Step 7: p.next is 10’s node, p.next.next is 30’s node, its data is 30. Field access compiles because Link’s fields are public. Step 8: the answers. A (10) is p.next.data. C (5) assumes the chain is 20, 10, 5. D and E assume q.setNext(null) cut the chain in the middle.
