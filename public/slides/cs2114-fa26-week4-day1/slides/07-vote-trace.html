Suppose a linked chain of Integers referenced by the variable head contains data 20, 30, 10, 5 in that order. Consider the execution of the following snippet:

the snippet

  1. Link p = head;
  2. Link q = p.getNext();
  3. Link r = q.getNext();
  4. p.setNext(r);
  5. q.setNext(null);
  6. r.setNext(q);
  7. Integer myVal = p.next.next.data;
  8. System.out.println(myVal);

  1. 10

  2. 30

  3. 5

  4. null

  5. Nothing; A Null Pointer Exception is thrown

Answer: B — 30. Silent first answer, then start the timer with one press; press again to move on. The three setNext calls each change one reference: 20’s node now points to 10’s node, 30’s node points to null, 10’s node points to 30’s node. The chain from head is 20, 10, 30, and the node holding 5 is unreachable. The last line reads fields directly (p.next.next.data), which compiles because Link’s fields are public: p.next is 10’s node, p.next.next is 30’s node, its data is 30. E is chosen by students who think q.setNext(null) cut the chain in the middle; it made 30 the last node. C is chosen by students who stop after the first setNext.
