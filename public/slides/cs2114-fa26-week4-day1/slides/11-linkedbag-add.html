LinkedBag.add: a new node at the front, in constant time

On the left, an editor with a program-counter bar and the seven lines of LinkedBag’s add method: public boolean add of T newEntry; Node newNode equals new Node of newEntry; newNode dot next equals firstNode; firstNode equals newNode; numberOfEntries plus plus; return true; and the closing brace. On the right, a chain: a blue pill labelled firstNode points down at a node holding ant, which points at bee, which points at cat, which points at the word null; under the chain, numberOfEntries equals 3. Step one: a new node holding dog appears to the left of the chain, its next compartment reading null. Step two: an arrow draws from the new node to ant, and its null disappears. Step three: the firstNode arrow moves from ant to the new node. Step four: the 3 is struck through and a 4 appears beside it. Step five: the caption reads that this is constant time — no array, no resizing, no shifting — and that traversals cost more. A caption under the editor changes with each step.

LinkedBag.add — module 4.3

  1. public boolean add(T newEntry) {
  2. Node newNode = new Node(newEntry);
  3. newNode.next = firstNode;
  4. firstNode = newNode;
  5. numberOfEntries++;
  6. return true;
  7. }

A new node holding dog. Its next is null; it is not in the chain yet.

newNode.next = firstNode: the new node points to the old first node.

firstNode = newNode: firstNode now points to the new node. If lines 3 and 4 were swapped, the chain would be lost.

numberOfEntries++: the count goes from 3 to 4.

Constant time: no array, no resizing, no shifting. Traversals (contains, remove) cost more; that is Week 5.

Same interface as Week 3, with a chain instead of an array. Step 1, line 2: a new node holding dog; its next is null, so it is not in any chain yet. Step 2, line 3: the new node points to the old first node, ant. dog, ant, bee, cat is now a chain, but firstNode still refers to ant. Step 3, line 4: firstNode now refers to dog. Ask what happens if lines 3 and 4 are swapped: firstNode refers to dog first, then dog.next = firstNode makes dog point to itself, and ant, bee, cat are unreachable. Step 4: numberOfEntries goes from 3 to 4. Step 5: the same steps for any chain length — no full array, no resizing, no shifting. Traversals (contains, getFrequencyOf, remove) are where the chain costs more; that comparison is Week 5. If time is short, skip this slide; the practice map covers add and toString.
