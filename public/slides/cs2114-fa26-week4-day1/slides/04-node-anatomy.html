class Link — the members the questions use

  1. public Object data;
  2. public Link next;
  3. Link(Object dataIn, Link nextIn) {
  4. this.data = dataIn; this.next = nextIn;
  5. }
  6. void setNext(Link newNext) { next = newNext; }
  7. Link getNext() { return next; }
  8. Object getData() { return data; }
  9. void setData(Object newData) { data = newData; }

head refers to a Link holding 20. Its next is null.

data holds the value. It is an Object, so any type fits; here an Integer.

next holds a reference to another Link. null means there is no next Link.

Link n2 = new Link(3, null): a new Link with data 3 and next null. It is not in the chain yet.

head.setNext(n2): the first Link’s next now refers to n2’s Link. The chain is 20, 3.

head.getNext() returns the reference stored in next: the Link holding 3. Every loop moves this way.

n2.getData() returns 3, the value in data.

n2.setData(30) replaces the value in data. next is not affected.

Two more Links the same way: 20, 30, 10, 5. This is the chain in Vote 1. Link’s fields are public, so p.next.data compiles.
