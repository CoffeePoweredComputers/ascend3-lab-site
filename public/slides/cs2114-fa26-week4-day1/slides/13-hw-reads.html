curr = firstNode; while (curr.getNext() != null) curr = curr.getNext(); — curr ends on the last node. Empty chain: firstNode is null, return null. toString is the same walk, building a String.

Look at curr.getNext() before moving: stop when its next is null (second-to-last) or its data equals the value (node before). Guard: while (curr != null && curr.getNext() != null). One-node or empty chain: null.

curr.getData().equals(value): for the first match, return curr at once; for the last, remember it and keep walking to the end. No match: null.

slow moves one node, fast moves two, while (fast != null && fast.getNext() != null). Middle: slow when the loop ends (A B C D: C). Loop: fast comes round and equals slow instead of reaching null.
