Which of the following correctly doubles every other value in any arbitrary linked chain of Integers, starting with the first node referenced by head (i.e., positions 0, 2, 4, …)?

    1. Link curr = head;
    2. while (curr != null) {
    3. curr.setData((Integer) curr.getData() * 2);
    4. curr = curr.getNext();
    5. if (curr != null) {
    6. curr = curr.getNext();
    7. }
    8. }
    1. Link curr = head.getNext();
    2. while (curr != null) {
    3. curr.setData((Integer) curr.getData() * 2);
    4. curr = curr.getNext();
    5. if (curr != null) {
    6. curr = curr.getNext();
    7. }

    2. while (curr != null && curr.getNext() != null) {
    3. curr.setData((Integer) curr.getData() * 2);
    4. curr = curr.getNext().getNext();
    5. }
    1. Link curr = head;

    5. }
Answer: A. The question as printed: “Which of the following correctly doubles every other value in any arbitrary linked chain of Integers, starting with the first node referenced by head (i.e., positions 0, 2, 4, …)?” Silent first answer, then the timer. On a four-node chain like Vote 1’s, C and D also work; they fail on odd lengths. B starts at head.getNext(), positions 1, 3, 5, and throws on an empty chain. C’s condition curr.getNext() != null stops it before the last node of an odd-length chain, so that node is not doubled. D calls curr.getNext().getNext() without checking; on the last node of an odd-length chain curr.getNext() is null and the call throws a NullPointerException. A moves one node, checks for null, then moves one more. If a group says C and D work, ask them to try a chain of three. Runestone activity: vtcs2_linkedchains_tracing_5_202507.
