VOTE 2 · THE ANSWER

A. B, C and D fail on an odd-length chain.

Four lanes in a two-by-two grid, one per option, each showing the same three-node chain holding 1, 2 and 3 with a null at the end, and a pill labelled curr under the node it is on. Step one: curr appears under the first node in lanes A, C and D, and under the second node in lane B. Step two: the node curr is on is doubled in every lane — 1 becomes 2 in A, C and D; 2 becomes 4 in B. Step three: curr moves two nodes along. In A and D it lands on the third node. In B it runs off the end; a cross appears and the lane reads prints 1, 4, 3. In C the loop’s guard stops it with the third node untouched; a cross appears and the lane reads prints 2, 2, 3. Step four: A doubles the third node, 3 becomes 6, curr steps off the end and a tick appears: prints 2, 2, 6. D doubles the third node too, then asks null for its next: a maroon cross lands on the null and the lane reads NullPointerException. Step five: the four answers return under the lanes, B, C and D struck through in turn and A left standing; the caption says that on a four-node chain C and D also give the right answer, so odd-length and empty chains must be tested.

Line 1: A, C and D start curr at head. B starts at head.getNext(), position 1.

First iteration: each doubles the node curr is on.

curr moves two nodes. B reaches null and stops: 1, 4, 3. C’s condition fails because node 3’s next is null: 2, 2, 3.

A doubles node 3, moves to null, and stops. D doubles node 3, then calls getNext() on null.

Only A is correct for every length. On a four-node chain, C and D also give the right answer. Test odd-length and empty chains.

  1. correct for every length
  2. starts at position 1
  3. skips the last node of an odd-length chain
  4. NullPointerException on an odd-length chain
Answer: A. All four run on a chain of three; odd length is where C and D differ from A. Step 1: A, C and D set curr to head; B sets curr to head.getNext(), the second node. Step 2: each doubles the node curr is on — 1 becomes 2 in A, C and D; B doubles 2 to 4. Step 3: moving two nodes. A: to node 2, check, to node 3. B: to node 3, then to null; the loop ends with 1, 4, 3. C: curr.getNext().getNext() reaches node 3; the condition curr.getNext() != null is false, so the loop ends with node 3 not doubled: 2, 2, 3. D: reaches node 3; its condition only checks curr != null, so it continues. Step 4: A doubles node 3, moves to null, stops: 2, 2, 6. D doubles node 3, then calls curr.getNext().getNext(); node 3’s next is null, so getNext() on null throws a NullPointerException. Step 5: on Vote 1’s four-node chain, C and D both produce 40, 30, 20, 5 and look correct. “Any arbitrary chain” means test odd-length, one-node and empty chains. A is the only loop that never calls a method on null. The practice problems test the same thing.
