Which of the following relationships best supports code reuse and good object-oriented design?

You are designing a system to manage items for an athletic store. The system must represent:

  • Shoe objects, which have size, brand, and traction type
  • Shirt objects, which have size, sleeve length, and material
  • WaterBottle objects, which have volume and insulation type
  • All items must track a product ID and a price.
  1. A

    Make Shoe, Shirt, and WaterBottle all subclasses of a Product superclass with shared fields productID and price

  2. B

    Make Shoe and Shirt subclasses of Clothing, and have only WaterBottle as a subclass of a Product class

  3. C

    Make Shoe a subclass of Shirt since they both have a size, and have WaterBottle unrelated.

  4. D

    Do not use inheritance; define each class separately with all needed fields

  5. E

    Use a common interface Item implemented by all three classes, with no shared fields in a superclass
