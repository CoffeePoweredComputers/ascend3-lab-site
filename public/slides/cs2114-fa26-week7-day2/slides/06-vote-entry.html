A peer-instruction question. Under the title, the stem in muted type: consider the following method. Left, an editor with seven lines: public void example of int x; print Entry plus x; if x is greater than 1, call example of x minus 1; then print Exit plus x; closing brace. Right, the question: if example of 3 is called, what is the order of printed lines? Then four options, each led by a maroon disc with its letter. A: Entry 3, Entry 2, Entry 1, Exit 1, Exit 2, Exit 3. B: Entry 1, Entry 2, Entry 3, Exit 3, Exit 2, Exit 1. C: Entry 3, Exit 3, Entry 2, Exit 2, Entry 1, Exit 1. D: Entry 3, Entry 2, Exit 2, Entry 1, Exit 1, Exit 3. Two clocks sit in the top right corner: a ninety-second vote timer and a two-and-a-half-minute discussion timer. The first press starts the vote timer; the second starts the discussion timer and ends the vote timer. Nothing else builds.

Consider the following method:

example

  1. public void example(int x) {
  2. System.out.println("Entry " + x);
  3. if (x > 1) {
  4. example(x - 1);
  5. }
  6. System.out.println("Exit " + x);
  7. }

If example(3) is called, what is the order of printed lines?

  1. A

    Entry 3 → Entry 2 → Entry 1 → Exit 1 → Exit 2 → Exit 3

  2. B

    Entry 1 → Entry 2 → Entry 3 → Exit 3 → Exit 2 → Exit 1

  3. C

    Entry 3 → Exit 3 → Entry 2 → Exit 2 → Entry 1 → Exit 1

  4. D

    Entry 3 → Entry 2 → Exit 2 → Entry 1 → Exit 1 → Exit 3

Answer: A — Entry 3, Entry 2, Entry 1, Exit 1, Exit 2, Exit 3 [ASSUMED by tracing; the key is not in the Runestone paste; confirm in Runestone’s results view]. Press once: the 1:30 vote clock; press again for the 2:30 discuss clock; press again to move on.
