BEFORE THE CALL · A WALK

print(n) above the call: it runs on the way in

A walkthrough of a five-line method under a program-counter bar: void count of int n; if n equals 0, return; print n; count of n minus 1; closing brace. On the right, the call stack drawn as boxes stacked from the bottom up, and a white plate labelled output. Step one: count of 3 is called and its box appears with n equals 3. Step two: it prints 3. Step three: it calls count of 2; a new box appears on top and the box below is marked waiting on line 4. Steps four to seven: count of 2 prints 2 and calls count of 1, count of 1 prints 1 and calls count of 0. Step eight: n is 0, so count of 0 returns and its box fades. Step nine: the three remaining boxes finish one after another and fade, because nothing is left after the call. The output reads 3 2 1. Step ten: the rule: a line above the call runs on the way in.

count(n), print above the call

  1. void count(int n) {
  2. if (n == 0) { return; }
  3. print(n);
  4. count(n - 1);
  5. }

called as count(3)

count(3) is called: a frame with its own n = 3. n is not 0, so it carries on.

print(n) comes first: 3.

count(3) calls count(2) and waits on line 4. The new frame has its own n = 2.

count(2) prints 2.

count(2) calls count(1) and waits.

count(1) prints 1.

count(1) calls count(0) and waits. Four frames.

n is 0: the base case returns. Its frame comes off and count(1) picks up after its call.

After the call there is only the closing brace, so count(1), count(2) and count(3) each finish. Output: 3 2 1.

A line above the call runs on the way in, before the next call starts.

A small method, different from last class’s fact: count(n) prints n and then counts down from n − 1. print(n) is short for System.out.print. Watch where the print sits: above the recursive call. Step 1 — count(3) is called; one frame with its own n. n is not 0, so we go on. Step 2 — print(n): 3. Step 3 — count(3) calls count(2) and waits on line 4; a new frame, its own n. Step 4 — count(2) prints 2. Step 5 — count(2) calls count(1) and waits. Step 6 — count(1) prints 1. Step 7 — count(1) calls count(0). Four frames on the stack. Step 8 — n is 0, the base case returns; that frame comes off and count(1) picks up on the line after its call. Step 9 — the line after the call is the closing brace, so there is nothing left to do: count(1), count(2), count(3) finish one after another. The output is 3 2 1, and all of it printed on the way in. Step 10 — the rule for the top half: a line above the call runs on the way in. Next: the same method with one line moved.
