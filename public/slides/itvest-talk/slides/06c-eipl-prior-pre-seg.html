How EiPL grading got here

A typical EiPL question
prompt
"Describe what this function does, at a high level."
def f(xs):
    a = list(xs)
    n = len(a)
    for i in range(n):
        for j in range(0, n - i - 1):
            if a[j] > a[j + 1]:
                t = a[j]
                a[j] = a[j + 1]
                a[j + 1] = t
    return a
expected (high-level)
"Returns a sorted copy of the list."
Prior approaches
EiPE introduced
2006 – 2008
Lopez, Whalley et al. — describing code at a high level predicts ability to write it. Graded manually.1,2
NLP autograder
2021
Fowler et al. — classifier trained on labelled student responses. Per-question labels required.3
CGBG
2024
Code-Generation-Based Grading — feed the response to an LLM, run unit tests. No per-question labels.4
+ pro
CGBG scales autograding
– con
but doesn't natively distinguish high- from low-level responses
