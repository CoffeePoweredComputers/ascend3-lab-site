Act II · activity 02

Prompt Problems

The inverse of EiPL. Students see a behavioral specification and must write the prompt that generates correct code.

input
A task
A worked example or visualization shows what the code should do. No code provided.
student work
A description
Natural language. Decomposition, edge cases, constraints — all in prose.
graded by
An LLM
The model generates code from the prompt. Tests run. The description's quality is the code's correctness.

A correct description is one that an LLM can turn into functionally equivalent code.

This shifts assessment from can you produce code? to can you specify intent precisely enough that something else can produce code? — which maps directly to the GenAI workflow.
