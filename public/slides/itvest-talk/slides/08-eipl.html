Act II · activity 01

Explain in Plain Language / EiPE

Students describe, in natural language, what a given piece of code does.

the trick
A description is correct if an LLM can generate functionally equivalent code from it.1
why it works at scale
Immediate feedback · ease of question authoring · no per-question human labeling.2
multistructural
"It loops through the list. It checks each value. It returns the largest."
relational
"It returns the largest value in the list."

Relational responses grade most reliably; we use LLM-based segmentation against the SOLO taxonomy to distinguish them.3

  1. 1EiPL → code-gen autograding (Smith IV et al.).
  2. 2Fowler et al. SIGCSE 2021.
  3. 3SOLO segmentation pipeline.
