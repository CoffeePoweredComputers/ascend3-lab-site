[0:50 → 2:05 · budget 1:15 · ~6 clicks] GenAI moves the skill from writing code to specifying it — so how do you grade a natural-language answer at scale? Code-generation-based grading. (1) The student's text — here a prompt — types in. (2) It goes to an LLM, which generates code. (3) The code runs against unit tests. (4) Pass or fail comes back as feedback — in under two seconds. (5) Finale: so what IS the question prompt when students write the prompt? That question splits into our first two problem types. Two of the four types run on this engine; the other two don't need an LLM at all.
