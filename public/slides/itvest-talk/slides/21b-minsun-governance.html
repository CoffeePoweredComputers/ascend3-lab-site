the problem
GenAI coding tools are harder to use well than they look.
Students need more support than ever — not less. Two kinds, often conflated:
USING THE TOOL
Getting from a vague intent to a workable output in this specific moment.
LEARNING TO USE IT WELL
Self-regulated learning & metacognition — knowing when you’re being helped vs. carried.
what minsun is working on
User-configurable GenAI assistants.
Tools where the learner or instructor can dial what kind of help shows up, when, and how much. The aim is an assistant that supports learning to learn, not one that just answers.
