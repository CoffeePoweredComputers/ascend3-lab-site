What we assess in CS1

Four learning objectives for decades. GenAI, recent work argues, demands two more.1,2

Write
Produce code from scratch.
Trace
Predict what code does.
Comprehend
Explain code in words.
Testing
Verify behavior with tests.
Decompose
Break a problem apart.
Prompt
Say what you want, precisely.

My work sits on these two: prompting and code comprehension, at scale.
