Distinguishing high level from low level

A typical EiPL question
prompt
"Describe what this function does."
def f(xs):
    a = max(xs)
    b = min(xs)
    return a - b
Two ways students respond
low-level
describes the code’s implementation
"It calls max on the list, calls min on the list, and subtracts them."
→ 3 segments, one per line of code
high-level
describes the code’s purpose
"Returns the range of the list."
→ 1 segment, the whole function

Use an LLM to segment the response and align each segment to the code it talks about. Number of segments becomes a clear, transparent signal — a mechanism that operationalizes low- vs high-level for students.
