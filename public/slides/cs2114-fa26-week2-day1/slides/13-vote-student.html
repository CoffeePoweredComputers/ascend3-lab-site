What is the expected output of this snippet?

A second peer-instruction question. On the left, the Student class with a constructor, a setter and a print method, and under it a three-line program that makes an array of eighty Students, sets a name on the first slot and prints it. On the right, four answers to choose between.

Student.java

  1. public class Student {
  2. String name;
  3. public Student(String n) { name = n; }
  4. public void setName(String n) {
  5. name = n;
  6. }
  7. public void print() {
  8. System.out.println(name);
  9. }
  10. }

your program

  1. Student[] myClass = new Student[80];
  2. myClass[0].setName("Jordan");
  3. myClass[0].print();
  1. The code will not compile
  2. A NullPointerException is thrown
  3. Jordan
  4. None of the other choices
Answer: B — a NullPointerException on line 2. `new Student[80]` makes eighty slots, not eighty Students; every slot holds null until something is assigned into it. It compiles fine, which is exactly why A is tempting. This one matters for the projects: an array of objects has to be filled twice — once for the array, once for each element.
