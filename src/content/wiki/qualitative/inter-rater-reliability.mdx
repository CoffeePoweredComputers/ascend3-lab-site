**Inter-rater reliability (IRR)** quantifies how much independent coders agree, *corrected
for the agreement you'd expect by chance*. It belongs to the codebook/coding-reliability
path — and, importantly, **not every study should report it** <Cite id="mcdonald-2019" />
<Cite id="oconnor-joffe-2020" />.

The word that does the work is **independent**. A reliability coefficient is only meaningful
on a set the two coders code *separately, before discussing it* — so the
consolidate-as-you-go loop from the [previous lesson](/wiki/qualitative/codebook-and-team-coding)
(which builds the codebook by consensus) can't produce one. If you need a number, reserve a
fresh, un-reconciled set and code it independently first.

## First question: should you use IRR at all?

If themes are the *interpretive product of a reflexive researcher*, a reliability
coefficient measures the wrong thing <Cite id="braun-clarke-2019" />. Use this guide:

## Compute Cohen's κ — and see the paradox

Two coders mark whether a code is **present** or **absent** on each segment. Edit the 2×2
counts, or load a preset:

<KappaCalculator />

Try **Balanced** then **Kappa paradox**: observed agreement stays ~85%, but κ collapses.
That's the **kappa paradox** — when one category dominates, chance-corrected agreement is
deflated even though raters mostly agree <Cite id="feinstein-cicchetti-1990" />
<Cite id="cicchetti-feinstein-1990" />. The calculator reports **Gwet's AC1** right beside
κ <Cite id="gwet-2008" /> — on the paradox preset AC1 stays sensible while κ craters,
which is exactly why AC1 is the fairer summary under skew.

## Reading the number

A common (and explicitly *arbitrary*) benchmark set <Cite id="landis-koch-1977" />:

| κ | Strength of agreement |
| --- | --- |
| < 0.00 | Poor |
| 0.00–0.20 | Slight |
| 0.21–0.40 | Fair |
| 0.41–0.60 | Moderate |
| 0.61–0.80 | Substantial |
| 0.81–1.00 | Almost perfect |

<Callout type="warning" title="The thresholds are arbitrary">
Landis & Koch themselves call these cutoffs arbitrary. Report the coefficient, the
observed agreement, and your reasoning — not just a band label. A "substantial" κ on a
badly-defined codebook is still a bad analysis.
</Callout>
